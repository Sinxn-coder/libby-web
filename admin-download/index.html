How to Install Libby Admin

Step 1: Download the installer
Click the download button above to save Libby_Admin_Setup_v1.5.0.exe to your computer.
Step 2: Run the Setup Wizard
Open the downloaded file. Follow the on-screen instructions to review the Institutional Agreement, select your installation path, and enable Start menu / Desktop shortcuts.
Step 3: Sign in with Administrative ID
Launch Libby Admin directly from your Start Menu or Desktop. Enter your authorized campus administrative credentials to access the Circulation Desk and Management Console.

Windows SmartScreen & Security Information

Because this is an in-house institutional build distributed directly via the campus portal without a commercial third-party code signing certificate, Windows Defender SmartScreen may display an informational prompt ("Windows protected your PC") on first launch.

To proceed: click "More info" and then select "Run anyway". The installer is fully local, contains no adware or tracking, and is maintained directly by Etriq for Kamaliya Campus.

Uninstallation & Upgrades

To uninstall or update Libby Admin:

  • Open Windows Settings → Apps → Installed apps (or Control Panel → Programs and Features).
  • Locate Libby Admin and select Uninstall.
  • The uninstaller cleanly removes all application binaries, native libraries, and shortcuts without disturbing your server-side institutional database records.
